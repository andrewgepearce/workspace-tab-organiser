Workspace Tab Organiser rules

Rules are tried from top to bottom and the first match wins. Choose Add from URL and paste an address. Drag a row by its grip to change the order. Saving stores the whole list on this browser only. It is not synchronised. A rule added from the popup is saved immediately and appears at the end of this list.

A rule with no path matches every path on that hostname.

No rules yet. Add a rule from a URL, then save it on this browser.

    Automatic groups

    This runs after the rules above. Tabs that match none of them are grouped by hostname and the first path segment when at least 2 tabs share that key. Those groups are ordered from A to Z. A single tab stays unmatched and is sorted by its title. Turning this off leaves unmatched tabs where they are.
