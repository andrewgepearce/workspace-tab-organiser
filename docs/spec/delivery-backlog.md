# Delivery Backlog

**Last updated:** 2026-11-11

This is the single prioritised queue for Workspace Tab Organiser. Work 1 item at a time. Each completed item will leave the repository testable and documented. No implementation begins until Andrew starts an item, and no commit is made without his approval.

The authoritative behaviour is defined in [Workspace Tab Organiser System Design](opera-tab-organiser-system-design.md). Remaining documentation findings are in [System Design Gaps](opera-tab-organiser-system-design-gaps.md).

## Workflow

1. Read the specification and this queue. Select the first eligible `pending` item, or the item Andrew names.
2. Set the selected row to `in_progress` and check its scope and requirements.
3. Ask each material decision separately with lettered options, positive and negative impacts, an Other option and a recommendation where supported.
4. Implement only that item and add or update focused tests and documentation.
5. Run the repository's agreed default test command. It will pass before the row is marked `done`.
6. Update this queue, then provide a mini sprint review.
7. Offer a commit with its intended scope and message. Wait for Andrew's approval before committing.
